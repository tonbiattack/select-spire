# SELECT Spire（select-spire）

Slay the Spire × SQL のデッキ構築ローグライク。

> ステータス: 仕様段階（コード未着手）。まず Issue #1 でMVP仕様を確定する。

## コンセプト

カードがSQL句。カードを組み立ててクエリを1本作ることが、そのまま攻撃になる。敵はテーブル、スキーマは最初は一部しか見えないため、偵察して弱点を読む。

## 遊び方（想定）

1. 敵テーブルが提示される（スキーマは列名の半分だけ公開）
2. 手札のSQL句カードを並べてクエリを組み立てる
3. 実行してダメージを与える
4. 敵の反撃（列を隠す／NULLを混ぜる／行数を増やす）を受け、次のターンへ
